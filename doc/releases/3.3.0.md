# Diadem Macro 3.3.0

## 한국어

### 다운로드와 시작

- Windows 10 버전 2004 이상, x64용 `Macro-3.3.0-win-x64.exe` 하나를 내려받아 쓰기 가능한 폴더에서 실행하세요.
- 별도 설치 프로그램이나 .NET 설치가 필요하지 않습니다. 기존 설정과 `Save` 폴더는 유지하세요.
- 기존 단일 EXE 버전에서는 설정의 앱 업데이트로 전환할 수 있습니다.

### 변경 사항

- MCP 지원 AI 앱에서 자연어로 이벤트 구성을 편집할 수 있도록 로컬 MCP 도구 11개를 추가했습니다.
- 이벤트 트리·프로세스·등록 이미지 조회, 창 캡처, 이벤트 생성·수정·삭제·부모/자식 이동·순서 변경·저장을 제공합니다.
- ROI·유사도·반복·딜레이·물리 클릭 설정과 클릭 없는 단발 이미지 검색을 제공합니다.
- MCP와 화면은 같은 이벤트 목록과 기존 저장 경로를 사용합니다. 저장 실패는 메모리 반영 여부와 구분해 반환합니다.
- 매크로 실행·옵션/설정 편집·캡처·업데이트 중에는 MCP 편집을 받지 않습니다. 매크로 실행과 입력 전송 도구는 제공하지 않습니다.
- 공통 디자인의 앱 아이콘을 적용하고 사용하지 않는 배포 자료와 코드를 정리했습니다.

### MCP 연결

일반 실행에서는 MCP 서버가 열리지 않습니다. MCP를 사용할 때만 다음처럼 실행하세요.

```powershell
.\Macro-3.3.0-win-x64.exe --mcp
```

같은 PC의 AI 앱에서 **Streamable HTTP** 연결 주소를 `http://127.0.0.1:8192/mcp`로 지정하세요. 다른 포트는 `--mcp --mcp-port=8193`으로 지정할 수 있습니다. 선택적 `DIADEM_MCP_TOKEN` 환경 변수와 클라이언트의 Bearer 토큰으로 인증할 수 있습니다.

구성을 저장한 뒤 실제 실행은 앱의 **시작** 버튼을 사용하세요. Unity의 물리 클릭은 클릭을 수행하는 이벤트에서 켜야 합니다.

정식 .NET 10 SDK로 단일 EXE 게시 산출물을 생성했습니다. 앱 실행·MCP 클라이언트 연결·자동 업데이트 설치 테스트는 수행하지 않았습니다.

사용법: [한국어 README](https://github.com/EomTaeWook/DiademMacro/blob/3.3.0/README.md)

## English

### Download and start

- Download `Macro-3.3.0-win-x64.exe` for Windows 10 version 2004 or later, x64, and run it from a writable folder.
- No installer or separate .NET installation is required. Keep your existing settings and `Save` folder.
- Existing single-EXE releases can use the app update feature in Settings.

### Changes

- Added 11 local MCP tools for configuring events through an MCP-capable AI application.
- Inspect event trees, processes and template images; capture windows; create, update, delete, nest, reorder and save events.
- Configure ROI, similarity, repetition, delays and physical clicks, and run a single image search without sending input.
- MCP and the UI share the event collection and existing save path. Save failures distinguish in-memory changes from persisted changes.
- MCP editing is unavailable during macro execution, open options/settings dialogs, capture selection or updates. No tools start the macro or send input.
- Applied the shared app icon design and removed unused deployment materials and code.

### Connect MCP

The MCP server is disabled during normal startup. Launch with MCP explicitly enabled:

```powershell
.\Macro-3.3.0-win-x64.exe --mcp
```

Connect an AI application on the same PC using **Streamable HTTP** at `http://127.0.0.1:8192/mcp`. Use `--mcp --mcp-port=8193` for another port. Optional authentication uses the `DIADEM_MCP_TOKEN` environment variable and the same Bearer token in the client.

After saving, use **Start** in the app to run the macro. Enable Physical Click on the event that performs a click in Unity applications.

The single executable was published using the stable .NET 10 SDK. App startup, MCP client connections and automatic update installation were not runtime-tested for this release.
