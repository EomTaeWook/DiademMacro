# Diadem Macro 3.3.1

## 한국어

- 기존 **3.3.1 릴리스에 추가 배포**했습니다. Windows 단일 EXE를 갱신하고 Apple Silicon·Intel Mac용 자체 포함 `.app` ZIP을 추가했습니다.
- Mac에서는 **설정 → macOS 권한**에서 입력 제어와 화면 캡처를 각각 허용하세요. 대상 창을 표시한 상태에서 실제 마우스·키보드로 입력하며 최소화 창은 지원하지 않습니다.
- Mac 설정·기본 저장 파일·로그는 `~/Library/Application Support/DiademMacro`에 생성됩니다. Mac 자동 업데이트는 제공하지 않습니다.
- 설정에 **MCP 열기·닫기**, 열림 상태와 연결 주소 표시를 추가했습니다.
- 설정에서 MCP 포트를 변경할 수 있습니다. 기본값은 `8192`, 허용 범위는 `1024~65535`이며 저장하면 다음 실행에도 유지됩니다.
- 서버가 열려 있을 때는 포트 입력을 잠그고 실제 서버의 포트를 표시합니다. 포트 변경은 서버를 닫은 뒤 다시 열어 적용하세요.
- DPI 설정을 창 생성 전 초기화 코드로 옮겨 `WFO0003` 컴파일 경고의 원인을 수정했습니다. 모니터별 `PerMonitorV2` 모드를 사용합니다.
- 3.3.0의 로컬 MCP 이벤트 구성 기능을 포함한 Windows x64 자체 포함 단일 EXE입니다.
- `Macro-3.3.1-win-x64.exe`를 내려받거나 설정에서 **업데이트 확인 → 업데이트 후 재시작**을 사용하세요. 기존 설정과 `Save` 폴더는 유지하세요.

앱을 평소처럼 실행하고 **설정 → MCP 서버 → 포트 입력 → MCP 열기**를 누르세요. 같은 PC의 AI 앱에서 **Streamable HTTP** 연결에 화면에 표시된 주소를 등록한 뒤, 설정 창을 닫고 이벤트 구성을 요청하세요. 서버를 닫으려면 설정에서 **MCP 닫기**를 누르세요. 실행은 앱의 **시작** 버튼을 사용합니다.

Windows SDK 게시와 Mac ARM64·x64의 네이티브 컴파일·`.app` 패키징이 완료됐습니다. 앱 실행·권한 승인·다중 모니터 배율 전환·실제 캡처·입력·MCP 연결·자동 업데이트 설치의 런타임 테스트는 수행하지 않았습니다. Mac 앱은 ad-hoc 서명이며 Apple 공증은 받지 않았습니다.

다운로드: [Windows x64 EXE](https://github.com/EomTaeWook/DiademMacro/releases/download/3.3.1/Macro-3.3.1-win-x64.exe), [Mac Apple Silicon ZIP](https://github.com/EomTaeWook/DiademMacro/releases/download/3.3.1/Macro-3.3.1-osx-arm64.zip), [Mac Intel ZIP](https://github.com/EomTaeWook/DiademMacro/releases/download/3.3.1/Macro-3.3.1-osx-x64.zip)

Mac은 ZIP을 풀고 `Diadem Macro.app`을 응용 프로그램 폴더로 옮겨 실행하세요. 별도 .NET 설치는 필요하지 않습니다. Mac ZIP마다 SHA-256 파일을 함께 제공합니다.

사용법: [한국어 README](https://github.com/EomTaeWook/DiademMacro/blob/master/README.md)

## English

- Updated the **existing 3.3.1 release** with a refreshed Windows EXE and self-contained Mac `.app` ZIPs for Apple Silicon and Intel.
- On Mac, grant input control and screen capture separately under **Settings → macOS permissions**. Keep the target window visible: input uses the real mouse and keyboard, and minimized windows are unsupported.
- Mac settings, default saved events, and logs are created under `~/Library/Application Support/DiademMacro`. Mac automatic updates are not provided.
- Added **Open MCP / Close MCP** controls, server status and the connection URL to Settings.
- Configure the MCP port in Settings. The default is `8192`, the allowed range is `1024` to `65535`, and saving retains the port for future launches.
- Port editing is locked while the server is open, and Settings shows its actual port. Close the server before changing the port and reopen it to apply the change.
- Moved DPI configuration to startup code before any windows are created, addressing compiler warning `WFO0003`. The app uses per-monitor `PerMonitorV2` mode.
- Windows x64 self-contained single EXE, including local MCP event configuration introduced in 3.3.0.
- Download `Macro-3.3.1-win-x64.exe` or use **Check for updates → Update and restart** in Settings. Keep your existing settings and `Save` folder.

Launch the app normally, open **Settings → MCP server**, enter the port and select **Open MCP**. Register the displayed URL as a **Streamable HTTP** connection in an AI app on the same PC. Close Settings before configuring events. Use **Close MCP** in Settings to stop the server and **Start** in the app to execute the macro.

Windows SDK publishing and native compilation / `.app` packaging for Mac ARM64 and x64 completed. App startup, permission approval, switching between monitors with different scaling, actual capture and input, MCP connections, and automatic update installation were not runtime-tested. Mac apps use ad-hoc signatures and have not been notarized by Apple.

Downloads: [Windows x64 EXE](https://github.com/EomTaeWook/DiademMacro/releases/download/3.3.1/Macro-3.3.1-win-x64.exe), [Mac Apple Silicon ZIP](https://github.com/EomTaeWook/DiademMacro/releases/download/3.3.1/Macro-3.3.1-osx-arm64.zip), [Mac Intel ZIP](https://github.com/EomTaeWook/DiademMacro/releases/download/3.3.1/Macro-3.3.1-osx-x64.zip)

On Mac, extract the ZIP, move `Diadem Macro.app` to Applications, and open it. No separate .NET installation is required. A SHA-256 file is included with each Mac ZIP.

Full guide: [English README](https://github.com/EomTaeWook/DiademMacro/blob/master/README.en.md)
