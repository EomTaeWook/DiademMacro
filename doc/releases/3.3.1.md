# Diadem Macro 3.3.1

## 한국어

- DPI 설정을 매니페스트에서 창 생성 전 초기화 코드로 옮겨 `WFO0003` 컴파일 경고의 원인을 수정했습니다. 모니터별 `PerMonitorV2` 모드를 사용합니다.
- 3.3.0의 로컬 MCP 이벤트 구성 기능을 포함한 Windows x64 자체 포함 단일 EXE입니다.
- `Macro-3.3.1-win-x64.exe`를 내려받거나 설정에서 **업데이트 확인 → 업데이트 후 재시작**을 사용하세요. 기존 설정과 `Save` 폴더는 유지하세요.

MCP를 사용할 때는 다음처럼 실행하고 같은 PC의 AI 앱에서 **Streamable HTTP**, `http://127.0.0.1:8192/mcp`로 연결하세요.

```powershell
.\Macro-3.3.1-win-x64.exe --mcp
```

앱 실행·다중 모니터 배율 전환·MCP 연결·자동 업데이트 설치의 런타임 테스트는 수행하지 않았습니다.

사용법: [한국어 README](https://github.com/EomTaeWook/DiademMacro/blob/3.3.1/README.md)

## English

- Moved DPI configuration from the manifest to startup code before any windows are created, addressing compiler warning `WFO0003`. The app uses per-monitor `PerMonitorV2` mode.
- Windows x64 self-contained single EXE, including local MCP event configuration introduced in 3.3.0.
- Download `Macro-3.3.1-win-x64.exe` or use **Check for updates → Update and restart** in Settings. Keep your existing settings and `Save` folder.

To use MCP, launch with the following argument and connect an AI app on the same PC using **Streamable HTTP** at `http://127.0.0.1:8192/mcp`:

```powershell
.\Macro-3.3.1-win-x64.exe --mcp
```

App startup, switching between monitors with different scaling, MCP connections and automatic update installation were not runtime-tested.

Full guide: [English README](https://github.com/EomTaeWook/DiademMacro/blob/3.3.1/README.en.md)
