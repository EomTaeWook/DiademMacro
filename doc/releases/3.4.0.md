# Diadem Macro 3.4.0

2026-11-04 00:43 KST [정식 릴리스](https://github.com/EomTaeWook/DiademMacro/releases/tag/3.4.0)를 공개했습니다. / Published as the latest stable release on 2026-11-03 at 15:43 UTC.

## 한국어

- 설정의 MCP 연결 주소 옆 **복사** 버튼으로 주소를 복사할 수 있습니다. 복사에 성공하면 2초 동안 **복사됨**을 표시합니다.
- 메인 화면에 **검색 테스트**를 추가했습니다. 프로세스와 이벤트를 선택하면 클릭·키보드 입력 없이 한 번 검색하고 유사도·임계값·찾은 좌표를 오른쪽 미리보기에 표시합니다.
- 관심 영역(ROI)과 항목별 유사도를 사용하며, 일치한 이미지에만 테두리를 표시합니다. 검색 중 **Esc**로 취소할 수 있습니다.
- Windows와 Mac 업데이트 처리를 DI로 분리했습니다. Windows는 기존 단일 EXE 교체 방식을 유지합니다.
- Mac은 실행 중인 앱의 ARM64·x64에 맞는 ZIP을 다운로드하고 SHA-256·번들 정보·서명을 확인한 뒤 `.app` 전체를 교체하고 다시 실행합니다. 교체·재실행 요청 실패 시 원본 복원을 시도하며 설정·저장 데이터는 사용자 폴더에 유지합니다.
- 공통 계열의 단순한 왕관 아이콘과 정리된 시작·종료 팝업을 포함합니다.

## English

- Added a **Copy** button beside the MCP endpoint in Settings, with **Copied** feedback for two seconds after success.
- Added **Test search** to the main window. Select a process and an event to search once without mouse or keyboard input, then inspect similarity, threshold and capture coordinates in the preview.
- Search tests respect ROI and per-event similarity, outline matches only, and support **Esc** cancellation.
- Separated Windows and Mac update behavior through dependency injection. Windows retains its single-EXE replacement flow.
- Mac selects the ZIP matching the running app's ARM64 or x64 architecture, verifies SHA-256, bundle metadata and signatures, replaces the complete `.app`, and requests a relaunch. It attempts to restore the original if replacement or relaunch fails. User settings and save data remain outside the bundle.
- Includes the simplified crown icon and refreshed startup/shutdown popup.

### Downloads and updates

Use the downloads in the table above. Windows users can download the standalone EXE or select **Check for updates → Update and restart** in Settings. Keep existing settings and save files.

Existing Mac releases require one manual `.app` replacement to gain automatic updates. Starting with 3.4.0, later higher versions can use the in-app update flow. Mac packages use ad-hoc signatures and have not been notarized by Apple.

MCP copying, matching/nonmatching image searches, ROI coordinates and Esc cancellation were checked in an isolated Windows run; the target test window received zero mouse and keyboard events. Those runtime checks predate the update DI changes. App execution, actual Mac updates, permission retention and failure recovery were not runtime-tested for this distribution.

Full guide: [English README](https://github.com/EomTaeWook/DiademMacro/blob/master/README.en.md)

## Build source / 빌드 소스

앱 소스와 릴리스 태그 기준 커밋은 [4719820](https://github.com/EomTaeWook/DiademMacro/commit/4719820d027743df4506dbe535ca3970dcc96271)입니다. Windows 단일 EXE의 제품 버전은 `3.4.0+4719820d027743df4506dbe535ca3970dcc96271`입니다.

- Mac Intel: [게시 작업](https://github.com/EomTaeWook/DiademMacro/actions/runs/41663270025/job/126011763487)이 성공했습니다. 같은 실행의 ARM64 작업은 러너 배정 대기로 취소했습니다.
- Mac ARM64: [교차 게시 작업](https://github.com/EomTaeWook/DiademMacro/actions/runs/41665444088)이 성공했습니다. 일회성 CI 분기의 [8586563](https://github.com/EomTaeWook/DiademMacro/commit/85865631dc7fd91253216fc50fe720b67969d6a5)은 앱 소스를 위 `4719820`으로 고정하고 Intel Mac 러너에서 ARM64 대상으로 게시합니다.
- 두 Mac ZIP의 버전·필수 파일·실행 권한·앱 실행 파일과 네이티브 라이브러리의 CPU·SHA-256을 확인했습니다. Windows EXE의 버전·소스 커밋·SHA-256을 확인했습니다.
- Mac 게시에는 `PortableBitmap`의 `CS0618`과 `File.GetUnixFileMode` 호출의 `CA1416` 경고가 남아 있습니다. 게시 컴파일은 성공했으며 실제 앱 실행·자동 업데이트 설치 검증은 포함하지 않습니다.

All three packages use app source `4719820`. The ARM64 job cross-publishes that pinned source on an Intel Mac runner. Package checks cover version, required bundle files, executable permissions, binary architecture and SHA-256; they do not establish runtime behavior. Mac publishing retains `CS0618` and `CA1416` compiler warnings.
