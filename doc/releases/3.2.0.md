# Diadem Macro 3.2.0

## 한국어

### 다운로드와 시작

- Windows 10 버전 2004 이상, x64용 `Macro-3.2.0-win-x64.exe` 하나를 내려받아 쓰기 가능한 폴더에서 실행하세요.
- 설치 프로그램과 별도 .NET 설치가 필요하지 않습니다. 설정·저장 이미지·로그는 사용 중에 생성됩니다.
- 기존 ZIP 버전에서는 새 EXE를 직접 내려받으세요. 기존 설정과 `Save` 폴더는 유지하세요.

### 변경 사항

- Avalonia 기반 화면과 한국어·영어 UI를 제공합니다.
- 이미지 검색에 완전 일치 탐색, 샘플 후보의 전체 픽셀 검증, 병렬 NCC 경로를 적용했습니다.
- 병렬 검색 작업에서 Bitmap 속성을 동시에 읽던 예외를 수정했습니다.
- 표시 중인 GPU 렌더링 창의 캡처와 실제 커서를 사용하는 물리 클릭을 지원합니다.
- 설정에서 로그 폴더를 열고 GitHub 정식 릴리스를 확인할 수 있습니다.
- 한국어·영어 README를 분리하고 부모·자식 AND 조건의 그림과 예제를 추가했습니다.

### Unity 사용 시

이미지를 찾았지만 클릭이 되지 않으면 **클릭을 실행하는 트리거의 옵션 → 입력 설정 → 물리 클릭**을 켜고 저장하세요. 자식 트리거가 클릭을 실행한다면 해당 자식에서 켭니다. 대상 창은 최소화하지 말고 클릭할 위치가 다른 창에 가려지지 않게 하세요.

자세한 사용법: [한국어 README](https://github.com/EomTaeWook/DiademMacro/blob/master/README.md)

## English

### Download and start

- Download `Macro-3.2.0-win-x64.exe` for Windows 10 version 2004 or later, x64, and run it from a writable folder.
- No installer or separate .NET installation is required. Settings, saved images, and logs are created during use.
- To move from an older ZIP release, download the EXE manually and keep your existing settings and `Save` folder.

### Changes

- Avalonia-based interface with Korean and English support.
- Image search uses exact matching, full-pixel verification of sampled candidates, and parallel NCC fallback.
- Fixed exceptions caused by concurrent Bitmap property access during parallel search.
- Capture visible GPU-rendered windows and use physical mouse clicks.
- Open the log folder and check stable GitHub releases from Settings.
- Separate Korean and English guides, including an illustrated parent/child AND example.

### Unity applications

If an image is found but the button does not respond, enable **Options → Input Settings → Physical Click** on the trigger that performs the click, then save. If a child trigger clicks, enable it on that child. Keep the target visible and the click position clear of other windows.

Full guide: [English README](https://github.com/EomTaeWook/DiademMacro/blob/master/README.en.md)
