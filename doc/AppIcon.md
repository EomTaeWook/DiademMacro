# 앱 아이콘

## 스타일

같은 제품군의 둥근 사각 바탕·굵은 흰색 심벌·동일한 여백과 선 굵기를 사용한다. Diadem Macro는 청록색 #2B777A 바탕에 흰색 24px 윤곽선의 세 봉우리 왕관 하나로 표현한다. 이름·제작자 표시·재생 삼각형·금색·그라데이션·그림자는 넣지 않는다. 둥근 사각형 바깥은 투명하다.

## 적용 경로

- `Macro.App/Assets/AppIcon.svg`: 색상과 도형의 원본이다. 256 좌표계에서 배경은 8px 여백·240px 크기·55px 모서리 반경이며 왕관은 굵고 둥근 흰색 윤곽 경로 하나다.
- `Macro.App/Assets/AppIcon.png`: 같은 SVG 도형을 .NET WPF로 내보낸 1024px PNG다. 메인 화면과 Mac 앱 번들에서 사용한다.
- `Macro.App/Assets/AppIcon.ico`: SVG 좌표에서 16·20·24·32·40·48·64·96·128·256px 프레임을 각각 그려 만든다. 실행 파일과 창의 기존 ICO 참조를 유지한다.
- 메인 화면의 아이콘은 기존 48px 크기를 유지하며 PNG 자체의 투명 모서리를 사용한다. 별도 모서리 클립은 두지 않는다.
- README의 실제 이벤트 화면 캡처는 유지한다.

이번 공통 계열 자산은 같은 SVG에서 .NET WPF로 PNG와 10크기 ICO를 생성했다. 이전 SVG·PNG·ICO는 교체 전 백업했다. 기존 artifacts/AppIcons/Generate-BlueCrownIcon.ps1은 앞선 파란색 채움 왕관의 제작 기록이다. 이번 아이콘 작업에서는 자산 제작·교체와 문서 반영을 수행했으며 앱 빌드·테스트·실행·배포는 수행하지 않았다.
